# Nyenrode Advanced IT: Buderus case (Group 3)

Shared workspace for the group assignment in the Advanced IT Program at Nyenrode Business University: a **Point of View** for the fictional company Buderus on integrating data analytics, AI and IoT into production and maintenance, presented to the board on **16 December 2026**.

When you open this repository in Claude, Copilot or Cursor, the assistant knows the case, the requirements and how our output should look.

## Start here

| File | What it gives you |
|---|---|
| [`CASE.md`](CASE.md) | The assignment, the ten requirements and the deliverables |
| [`AGENTS.md`](AGENTS.md) | Rules every AI agent follows |
| [`CLAUDE.md`](CLAUDE.md) / [`.github/copilot-instructions.md`](.github/copilot-instructions.md) | Tool-specific additions |
| [`DESIGN.md`](DESIGN.md) | Visual rules for pages and slides |
| [`VERSION_CONTROL.md`](VERSION_CONTROL.md) | How we branch, commit and review |
| [`analysis/business-case.md`](analysis/business-case.md) | Business case with labelled figures and sources |
| [`context/`](context) | Programme, frameworks, company reference, literature, open points |
| [`tools/pov-workpage/`](tools/pov-workpage/index.html) | HTML workpage that walks through the whole PoV |
| [`.claude/skills/pov-check/`](.claude/skills/pov-check/SKILL.md) | Checks a draft against the case requirements |
| [`materials/`](materials) | Case description, group drafts and writing guides |
